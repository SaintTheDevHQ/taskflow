
# TaskFlow - To-Do List App

TaskFlow is a simple and responsive task management application that helps users organize their daily activities, manage priorities, and keep track of completed tasks.

## Features

- Add new tasks
- Assign task priorities (High, Medium, Low)
- Display tasks dynamically
- Responsive user interface
- Delete tasks
- Mark tasks as completed
- Filter tasks by status
- Save tasks using Local Storage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
